# Hardening Modules

> [!WARNING]
> Hardening modules are currently under development (Phase 2).

When completed, the framework will support the following modules:
- SSH Security Enforcement
- UFW Firewall Configuration
- Sysctl Kernel Hardening
- User and Privilege Restrictions
- File System Permissions
- Services Minimization

To simulate the execution flow, you can run:
```bash
sudo ./scripts/harden.sh --dry-run
```
