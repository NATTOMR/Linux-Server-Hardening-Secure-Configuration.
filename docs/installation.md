# Installation Guide

## Requirements
- Supported OS: Ubuntu, Debian, Kali Linux
- Root privileges (`sudo`)
- Bash shell (version 4.0+)

## Quick Start
1. Clone the repository:
   ```bash
   git clone https://github.com/NATTOMR/Linux-Server-Hardening-Secure-Configuration.git
   cd Linux-Server-Hardening-Secure-Configuration
   ```

2. Make scripts executable:
   ```bash
   chmod +x scripts/*.sh scripts/lib/*.sh
   ```

3. Run the system information check to verify compatibility:
   ```bash
   ./scripts/system-info.sh
   ```
